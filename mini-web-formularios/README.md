# Mini web de formularios

Proyecto de práctica para Git y GitHub. Contiene 5 formularios:
registro, login, contacto, encuesta y pedido.

## Cómo abrirla
Abre `index.html` en el navegador.

## Ideas para practicar cambios (un commit por cada uno)
- Cambiar los colores en `css/styles.css`
- Agregar un campo nuevo a un formulario
- Cambiar el mensaje de validación en `js/script.js`
- Agregar un sexto formulario
